Unit 1

Classes, Method Overloading & Arrays

Implemented in Train.java, Passenger.java, and Ticket.java. Demonstrates constructor overloading, search method overloading, and passenger array manipulation.

Unit 2

Interface Reservable & Ticket Hierarchy

Interface Reservable with subclasses ACTicket and SleeperTicket. Uses method overriding for class-specific fare computation and official refund calculation.

Unit 3

Custom Exception & Thread Synchronization

Custom checked exception SeatNotAvailableException. Synchronized allocation via SynchronizedSeatAllocator.java ensuring thread safety during simultaneous bookings.

Unit 4

JDBC with PreparedStatement

BookingDAO.java executes parameterized queries protecting against SQL injection, managing transactions across trains, passengers, and tickets tables.

Unit 5

Java Swing GUI with Layouts & Adapters

RailwayReservationGUI.java builds desktop Swing interface utilizing BorderLayout (North title, Center forms, South actions) and FlowLayout with WindowAdapter and KeyAdapter event classes.
